![SuperformOS Strategy Canvas](/operate/images/screenshots/strategy.jpg)

Open **Strategy** for the intended chain and vault. Each card is a saved rule and action: the rule decides when to act, and the size and execution steps decide what to do.

[Write and update a strategy](/operate/strategy/quickstart) walks through a SuperStocks partial repayment, including safe edits to an existing definition. Follow its executions in [Intent History](/operate/ui/intent-history).

## Read the cards

| Lane | Actions | Purpose |
|---|---|---|
| Deposit | `DEPOSIT` | Deploy assets into a source |
| Redemption | `WITHDRAWAL`, `CLAIM` | Return source assets or claim proceeds |
| Rebalance | `REBALANCE`, `SWAP`, `BRIDGE`, `CLAIM_REWARDS` | Other supported movements and reward claims |

Public vault pages provide read-only strategy context. Opening an editor depends on inspection permissions; creating, editing, reordering, and starting strategies requires manager authority in Operate. A disabled control is not itself an engine error.

| State | Meaning |
|---|---|
| `CREATED` | Saved, not active |
| `IDLE` | Not evaluating rules |
| `RUNNING` | Eligible to evaluate and publish intents, subject to gates |
| `ERROR` | Inspect the error before restarting |
| `ARCHIVED` | Soft-deleted definition |

A running card is not proof of a fill. An inactive card can still have an earlier intent in flight.

## Inspect before editing

Open the definition and check its ID, version, state, position or source, rule tree, **Size expression**, and execution steps. Use **Variables** to select real fields and **Copy** to inspect the normalized engine expression, including raw-unit conversions.

Use **Add deposit strategy**, **Add redemption strategy**, or **Add rebalance strategy** for a new definition. **Create** and **Save** persist configuration; the lifecycle toggle starts or stops evaluation separately. Save a new or changed definition inactive, reopen it, and compare what was stored before activation.

Updates use a version. If another edit or state transition wins first, reload and reconcile the `409 Conflict` rather than overwriting it. Follow the [update procedure](/operate/strategy/quickstart#update-an-existing-strategy-safely) for threshold, size, or action changes.

## Order and execution gates

Drag within a lane to change server-managed priority. Create and update do not set priority. A reorder includes every non-archived strategy in the lane exactly once. Order helps select eligible signals; it does not sequence transactions across cards.

Cooldown and the editor's fixed one-concurrent-intent limit apply per strategy. They do not reserve a balance against other strategies. Conviction scores the current evaluation, not consecutive passing ticks.

A missing session key, kill switch, stale data, or execution-readiness failure can block publication even when a card is `RUNNING`. A target-scoped emergency lock also blocks affected user-defined strategies and disables their related controls. Operate special emergency exits from [Pause Operations](/operate/ui/pause), not the ordinary editor.

Stopping a strategy does not cancel in-flight execution or unwind its position. Inspect outstanding work in [Intent History](/operate/ui/intent-history) before enabling a replacement spender.
