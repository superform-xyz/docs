## Start from the position

In **Strategy**, select the chain and vault, then inspect the existing strategy before changing anything. Record its ID, version, state, rule, size, and execution steps. Use a prepared vault you are authorized to manage; [setup](/operate/ui/setup-checklist) is separate from writing the rule.

The worked example is **superNVDA AP0**, an idle-USDC partial repayment strategy captured on **19 October 2026**. It repays when LTV is at least 52% but below 55%, sizing toward 50% and capped by available USDC. These are dated example thresholds, not a universal SuperStocks policy. Other entry/deployment definitions in that capture retained 40% gates.

The surrounding carry flow supplies NVDAc collateral, borrows USDC, and deposits USDC into a yield source. This rule only spends USDC already idle at the execution strategy. It does not redeem source shares or withdraw collateral.

## Choose the variables

Open **Variables** in the rule builder. Select the debt amount, debt risk value, and collateral risk value for the **same position**, plus the execution strategy's idle USDC balance. Check their units before writing comparisons:

| Input | Unit | Use |
|---|---|---|
| USDC debt amount | Raw USDC, 6 decimals | Cap repayment by debt |
| Debt risk value | Risk value scaled by `1e18` | LTV numerator |
| Collateral risk value | Same risk-value scale | LTV denominator |
| Idle USDC | Raw USDC, 6 decimals | Available repayment funds |

The ratio of the two risk values gives LTV. They are not token amounts. `1` raw USDC is `0.000001` USDC. Do not use `vault_free_assets` for this repayment: superNVDA's underlying is NVDAc, not USDC.

## Build the rule

For a separate inactive exercise, choose **Add rebalance strategy** and name it `Partial USDC repay - inactive exercise`. Do not replace the running AP0 with this teaching definition.

In **Rule tree**, join these six conditions with an **AND** gate:

1. Raw debt amount is positive.
2. Debt risk value is positive.
3. Collateral risk value is positive.
4. Debt risk value is at least `0.52 × collateral risk value`.
5. Debt risk value is below `0.55 × collateral risk value`.
6. Idle USDC is at least one raw unit.

Use the editor's **AND / OR / NOT** gates, not pasted `&&`, `||`, or `!`. For this rule, **Copy** should preserve six expressions under one AND; the saved tree is an `AND` with six `EXPR` children.

## Size and configure repayment

The size is the fraction of raw debt above the 50% risk-value target, capped by both idle USDC and raw debt. The simplified formula below omits AP0's production interest/dust buffer so the target calculation is visible. It is an authoring example, not a replacement production policy.

<Accordion title="Paste the raw Size expression">

```text
min ( token_0x833589fcd6edb6e08f4c7c32d4f71b54bda02913_amount , min ( position_0xacaa6ee9de7631b927242d42fb8c256860545fa457560f550b653a925bc6cb3b_debt_0x833589fcd6edb6e08f4c7c32d4f71b54bda02913_amount , position_0xacaa6ee9de7631b927242d42fb8c256860545fa457560f550b653a925bc6cb3b_debt_0x833589fcd6edb6e08f4c7c32d4f71b54bda02913_amount * max ( position_0xacaa6ee9de7631b927242d42fb8c256860545fa457560f550b653a925bc6cb3b_risk_debt_value_e18 - 0.50 * position_0xacaa6ee9de7631b927242d42fb8c256860545fa457560f550b653a925bc6cb3b_risk_collateral_value_e18 , 0 ) / max ( position_0xacaa6ee9de7631b927242d42fb8c256860545fa457560f550b653a925bc6cb3b_risk_debt_value_e18 , 1 ) ) )
```

Paste the whole expression into **Size expression**, then use **Copy**. The block shows the expected normalized, space-separated engine expression. It is already in raw USDC: there must be no extra multiplication by `1e6`. **Literal / Formatted** changes the value display, not the units of an existing expression. If Copy changes more than spacing, test the copied result before saving.

</Accordion>

Select the registry-backed **AaveV4RepayHookV2** and confirm a single repayment step. The first input is raw USDC, not NVDAc or source shares. In this example the target type is `VAULT`, and the vault context differs from the token-holding execution strategy. Review the [captured repayment parameters](/operate/strategy/action-config#idle-usdc-repayment) against the selected position; let the editor resolve hook addresses and encoded arguments.

Under **Signal & risk**, choose **BINARY** in **Conviction** and enter **60** in **Cooldown (s)**. This saves `cooldown_ms: 60000`. The editor sets `max_concurrent: 1`; there is no editable concurrency control. The limit is per strategy, not a lock against other strategies spending the same USDC.

Review **Max slippage (bps)** and **Signal lifespan** for the plan. Captured AP0 used 2 bps and 60 seconds. Cooldown limits repeated publication; conviction does not count consecutive passing ticks.

## Check behavior before activation

With collateral risk value 100, USDC valued at 1, and unchanged collateral, the simplified expression gives:

| Debt / LTV | Idle USDC | Rule | Repayment, raw USDC | Modeled result |
|---|---:|---|---:|---|
| 51 / 51% | 10 | false | No intent | Below trigger |
| 52 / 52% | 10 | true | `2000000` | Debt 50, LTV 50% |
| 54 / 54% | 10 | true | `4000000` | Debt 50, LTV 50% |
| 54 / 54% | 1 | true | `1000000` | Debt 53, target not reached |
| 55 / 55% | 10 | false | No intent | Outside partial branch |
| Zero debt amount, debt value, or collateral value | 10 | false | No intent | Guard blocks |

These are evaluator cases, not transaction outcomes. Captured AP0's buffered size requests `4004001` raw USDC in the 54% case, rather than this guide's `4000000`. Keep an existing strategy's approved buffers when updating it.

Choose **Create**, reopen the saved definition, and confirm its ID, version, `CREATED` or `IDLE` state, rule, copied size, plan, and controls. Do not toggle it on to test it. There is no arbitrary-snapshot **Test** button or JSON-import step in this editor.

For [Simulation](/operate/ui/simulation), select the saved inactive strategy explicitly. AP0 can be admitted, but the model does not simulate its Aave debt reduction or prove post-action LTV. Test boundary and capped-size cases separately; do not treat a successful save or model run as transaction preflight.

## Update an existing strategy safely

1. **Read the current definition.** Reopen the intended card and record its current version and state. Compare its actual rule and size, not just its name, with the proposed change.
2. **Control ongoing activity.** If the edit can change spending or risk, use the lifecycle toggle to stop it before editing, within the approved operating scope. Check [Intent History](/operate/ui/intent-history) for outstanding intents and competing spenders. Stopping evaluation does not cancel an intent or submitted transaction; reconcile those outcomes before introducing another spender. Reopen the definition after stopping to load its new state and version.
3. **Make a bounded edit.** For a threshold change, review both edges of the trigger window and the separate sizing target. For a size change, preserve all three positive-value guards, the idle/debt caps, position binding, and approved interest/dust buffers. Lowering a trigger is not equivalent to changing the repayment target. Test the newly included boundary and a constrained-funds case.
4. **Save while inactive.** Choose **Save**, then reopen and compare the new version, inactive state, rule, size, and execution steps. Verify that unrelated hook parameters, risk controls, cooldown, and slippage stayed unchanged.
5. **Resolve conflicts without overwriting.** A `409 Conflict` means the version changed. Reload, compare the other edit or state transition, and reapply only the intended change after review. Do not just substitute a newer version and retry the old payload.
6. **Review and deliberately activate.** Test the saved definition, check fresh position data, balances, hook authorization, session readiness, gas, and other eligible strategies. Start only the approved definition with its lifecycle toggle. One concurrent intent does not make it “run once.”
7. **Trace the result.** In [Intent History](/operate/ui/intent-history), match the new intent to the strategy, inspect the fill and transaction, then refresh debt, collateral risk value, and idle USDC. Confirm actual repayment and residual debt before deciding whether further activity is appropriate.

A partial repayment can stop firing while debt remains. At 51% LTV this example is false, even if an earlier action began above the trigger. An unchanged rule name or a `COMPLETED` intent is not evidence that the 50% target was reached.
