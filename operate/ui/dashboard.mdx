## Read the selected vault

The Dashboard is vault-scoped. In Operate, select the intended chain and vault; public pages use `/supervaults/{chain_name}/{vaultAddress}` and expose read-only context without manager mutation controls.

Record observation times alongside values. A refreshing panel is not proof that every source, oracle, loan position, or service metric is fresh. Public visibility also does not grant access to all engine diagnostics.

## Vault accounting

| Quantity | Interpretation |
|---|---|
| USD TVL | Display valuation; not the engine's raw `vault_tvl` |
| Current PPS | Last recorded vault price per share |
| Calculated PPS | Offchain calculation, which can differ before the next accepted update |
| High-water mark | Fee-accounting reference, not a floor guaranteeing share price |
| Total supply | Vault shares, using vault share decimals |
| Free assets | Idle vault-underlying assets at the strategy; not arbitrary debt tokens |
| Escrowed/pending assets | Redemption-accounting state; not automatically spendable liquidity |
| Upkeep | Service funding/readiness, separate from execution gas |

PPS can decrease, including at a performance-fee skim. Do not interpret every downward step as an oracle failure or claim monotonic growth. Inspect the vault's fee configuration and reconcile the relevant update/skim event.

## Allocation versus realizable liquidity

A source allocation describes exposure, not the amount withdrawable immediately. Inspect source shares, asset-equivalent value, PPS, and asset/share exit liquidity separately. Async requests add pending and claimable stages; a position can remain economically owned while unavailable for immediate redemption.

Never convert a raw share balance using underlying-token decimals. [Variables and units](/operate/strategy/variables) explains the Clearstar 18-share / 6-USDC conversion and the difference between wire scale and human display.

## Lending positions

For each position, identify the venue, Spoke/market, reserve IDs, collateral/debt tokens, owner, and normalized position ID. Inspect:

- Raw collateral and debt amounts with token decimals.
- Collateral/debt risk-reference values using the same provider convention.
- Borrow/liquidation capacity and health measures where supplied.
- Borrow and supply rates, with their units and period.
- Observation freshness, not just last-known values.

LTV is debt reference value divided by collateral reference value. It is not raw USDC divided by raw NVDAc. A source-oracle address does not by itself establish a fresh stock price or hard venue threshold.

For the [carry case study](/operate/playbooks/carry), separate NVDAc collateral, USDC debt, Clearstar shares, idle USDC, and idle NVDAc. Debt repayment can succeed without releasing collateral or funding depositor redemptions.

## Operational readiness

| Surface | Question |
|---|---|
| Strategy lifecycle | Is the intended version RUNNING, IDLE, CREATED, or ERROR? |
| Engine state | Are feeds/indicators ready and referenced observations fresh? |
| Publication controls | Are cooldown, slots, locks, breaker, or kill switch suppressing new intents? |
| OMS/executor | Is the session key valid, authorization ready, and gas funded? |
| Intent History | Which operation was published and what actually settled? |
| Redemption queue | What value and age remain, and which requests are still outstanding? |

Missing telemetry is **unknown**, not healthy. A RUNNING card, sufficient upkeep, or a successful last fill does not prove every row above is ready now.

## Reconcile a change

Record a before snapshot, find the specific intent and receipt, then compare after values using the same tokens, scales, and valuation convention. Account for interest, fees, oracle changes, and intervening transactions. The [worked AP1 trace](/operate/ui/intent-history) demonstrates why aggregate output fields alone cannot explain an economic result.

Use [Monitoring and alerts](/operate/automation/monitoring) for collection and [Troubleshooting](/operate/strategy/troubleshooting) for stage-specific diagnosis. This page describes source-reviewed accounting concepts, not a guarantee that every public dashboard panel exposes authenticated position telemetry.
