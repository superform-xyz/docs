---
title: "Strategy Troubleshooting"
description: "Diagnose why a strategy is not saving, ticking, publishing, or filling."
---

Start at the stage that failed: save, evaluation, publication, or execution. A saved strategy is not necessarily running, and a true rule is not necessarily a published intent.

## First Checks

| Question | Where to check |
|----------|----------------|
| Is the strategy `RUNNING`? | [Strategy Canvas](/operate/ui/strategy) or `GET /api/v1/strategies/{id}`. |
| Is the vault active? | [Setup Checklist](/operate/ui/setup-checklist) and [Vault Settings](/operate/ui/vault-settings). |
| Does OMS have a valid session key? | Strategy Canvas gate and [OMS API](/operate/api/oms#session-keys). |
| Is the target whitelisted? | [Yield Source Management](/operate/ui/yield-sources). |
| Is the hook authorized? | [Merkle Trees](/operate/ui/merkle-trees). |
| Is an emergency lock active? | [Pause Operations](/operate/ui/pause) and engine shard state. |

## Create or Update Rejected

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| `unknown identifier` | Identifier policy rejects the name. | Select actual fields from **Variables** or a configured indicator. A valid alias still needs a live feed. |
| Rule or size type error | The rule must return boolean; size must return numeric. | Review [DSL types and grammar](/operate/strategy/dsl). Save validation is static, not an empty-snapshot run. |
| `missing objective` | `action_config.objective` is absent. | Add `MIN_SLIPPAGE`, `MIN_TIME`, or `BALANCED`. |
| `invalid address` | A configured address is malformed. | Re-select the registry-backed hook/source and verify its parameters. |
| `409 Conflict` | Another edit or state transition changed the version. | Reload and compare before reapplying the intended change. Do not overwrite with a stale payload. |

## Strategy Saves but Does Not Tick

| Cause | What to do |
|-------|------------|
| State is `CREATED` or `IDLE` | Transition to `RUNNING` after readiness checks. |
| Vault activation incomplete | Fund upkeep and clear setup checklist blockers. |
| Kill switch or vault pause active | Review Pause Operations and vault pause status. |
| Target emergency lock active | Stop the emergency exit only after the incident is resolved. |
| No shard state | Check Strategy Engine health and shard assignment for the vault. |

## Strategy Ticks but Does Not Publish

| Cause | What to do |
|-------|------------|
| Rule evaluates false | Inspect current shard inputs and engine diagnostics. Intent History shows published signals, not every false tick. |
| Runtime division by zero | Put positive-value guards before division, or compare by multiplication. |
| Data missing or stale | Confirm the position/source feed and units. Do not delete the guard to force publication. |
| `size_expr` is zero/negative | Rework sizing so it is positive when the trigger passes. |
| Missing session key | Grant or renew OMS session-key authorization. |
| Missing merkle proof | Generate, sync, and publish the active merkle tree. |
| Target not whitelisted | Add the yield source and oracle. |
| Cooldown or occupied slot | Check elapsed cooldown and outstanding intents. The editor fixes concurrency at one per strategy, not one per vault. |

## Intent Publishes but Does Not Fill

| Cause | What to do |
|-------|------------|
| OMS route failure | Inspect OMS events for planning or execution errors. |
| Hook transaction failed | Open the hook transaction in the explorer and compare calldata/proof. |
| Slippage too tight | Review `max_slippage_bps` against current liquidity. |
| Gas or nonce issue | Check executor wallet state and OMS event details. |
| Source liquidity changed | Check current asset/share exit liquidity and holdings; source TVL is not withdrawal availability. |

## Useful Endpoints

```bash
GET /api/v1/strategies/{id}
PATCH /api/v1/strategies/{id}/state
GET /api/v1/engine/shards/{vault_id}/state
GET /api/v1/intents?strategy_id={id}
GET /api/v1/intents/{intent_id}/events
GET /api/v1/intents/{intent_id}/fills
GET /api/v1/fills?strategy_id={id}
```

Stop repeated failures, preserve the ID/version, error, and last intent, and reconcile outstanding execution before editing. Follow [safe updates](/operate/strategy/quickstart#update-an-existing-strategy-safely); do not automatically archive/recreate a strategy or weaken its guards.

For simulation errors, see [Simulation](/operate/ui/simulation). AP1/AF2 liquidity inputs are unsupported by replay; removing those guards is not a fix.
