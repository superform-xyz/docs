Builder codes help you measure the SuperVault activity your integration routes. Add your registered code to Bundler requests, then view deposits, withdrawal requests, and attributed balances in SuperformOS.

Credit follows the code attached to each supported action. A user's first deposit does not permanently assign their future activity to your integration. Commercial terms are agreed separately; a code does not automatically earn fees or rewards.

## Request a code

Submit the form below. Use a nonzero EVM wallet address you control for payouts and code management. The wallet must be able to transact on the registry network. Codes use 1-32 lowercase letters, digits, or underscores: `^[a-z0-9_]{1,32}$`.

The team reviews requests manually and registers approved codes onchain. Wait for confirmation with your exact code and partner ID before integrating. Submitting the form does not register a code.

Form responses are private. Registered codes, payout addresses, and metadata are public onchain. Keep contact details out of public metadata.

## Add your code to requests

Follow the [Quickstart](/build/earn/quickstart) or [Deposit guide](/build/earn/deposit) for the full transaction flow. Add `builder_code` at the top level of the request body:

| Account flow | Request |
|---|---|
| Smart account | `POST /executor/build`, after `POST /hooks/suggest` |
| Non-smart-account | `POST /hooks/suggest/non-smart-account` |

Do not add it to smart-account `POST /hooks/suggest` or inside an action or hook.

This is a field-only JSON fragment, not a complete request. Replace `your_registered_code` with your exact registered code:

```json
{
  "builder_code": "your_registered_code"
}
```

Use the raw API request to pass this field; the [copy-paste clients](/build/sdk) do not expose it in their deposit helpers. Preserve the calldata returned by the Bundler.

## View activity

Open [Integrators in SuperformOS](https://os.superform.xyz/integrators), authenticate with your wallet, and paste your partner ID into the filter. Select 7, 30, or 90 days to view public partner aggregates and daily history:

- Deposits and withdrawal requests cover the selected period. Withdrawals count when requested.
- Net deposits and attributed balance include earlier history. Balance includes yield, not fees owed.
- Transfers, claims, and cancellations are excluded.

Multiple codes can share a partner ID. Allow time for indexing after an action; contact your Superform representative if activity is missing.

## Code control

Only the current payout wallet can update the code's payout address or metadata. Contact your Superform representative for guidance on these onchain changes.

<Warning>
Changing the payout address immediately transfers code-management control to the new wallet. The old wallet loses authority, with no acceptance step or admin override to recover a lost controller or reverse a mistaken transfer.
</Warning>
