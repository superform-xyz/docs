## Access checklist

- Open [SuperformOS](https://os.superform.xyz). Public discovery does not require manager access.
- For Operate, use **Connect**, complete the shared account flow, and accept the Superform terms if prompted. The user must review and accept terms themselves.
- Obtain a role for the exact **chain and vault address**. Primary and Secondary Managers can author strategies. Assigned view-only users can inspect rules but cannot save strategies or run simulations.
- Prepare the authorized transaction-signing wallet, and native gas on the target chain. Connecting a different wallet does not transfer a vault role.
- For a new vault, prepare the underlying token address and decimals, provider metadata, managers, fee recipient, and fee/timing configuration.

A private demonstration needs an explicitly authorized, isolated vault and inactive strategies. Base is a production network, not a sandbox.

## Configuration checklist

| Input | Check before use |
|---|---|
| Chain and vault | Use the selected network and deployed address, not a name-only search |
| Underlying asset | Verify token identity and precision; do not assume all SuperVaults use the same decimals |
| Source and oracle | Confirm the source's assets, shares, pricing denomination, freshness, and withdrawal limits |
| Hook plan | Confirm every target and parameter combination is authorized |
| Executor | Confirm manager membership and a valid delegated session |
| Funding | Check UP upkeep, execution gas, and strategy input balances separately |

Use the application's supported network choices and [Deployment Addresses](/deployment-addresses); network availability is not permission to reuse another chain's source or oracle configuration.

[Authentication](/operate/authentication) explains the browser session. [API boundaries](/operate/api/overview) identifies public reads and upstream service contracts. A documented service path is not a promise of public automation credentials. Arrange approved programmatic access with the Superform team before building a writer.
