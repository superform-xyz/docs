## Public discovery

[SuperformOS](https://os.superform.xyz) provides public vault discovery and read-only detail pages. Discovery is filtered by activation and visibility policy; it is not an inventory of every deployed contract. A missing list entry does not prove that a vault does not exist.

Select a vault by chain and address. Public detail uses `/supervaults/{chain_name}/{vaultAddress}` and exposes Dashboard, Strategy, Intent History, Hooks, Yield Sources, Roles, and Vault Settings views where public data is available. Manager controls remain in Operate. Public Strategy cards do not grant access to the authenticated rule editor.

## My SuperVaults

After [connecting](/operate/authentication), open **Operate → My SuperVaults**. This list is scoped to your assigned vault roles. If a vault is missing, check the connected account, chain, address, and role assignment before creating another vault.

The selected vault determines the context for Setup, Dashboard, Strategy, Simulation, Intent History, Hooks, Yield Sources, User Management, Vault Settings, Keepers, and Pause. Recheck this context before saving a definition or signing a transaction.

| Task | Surface |
|---|---|
| Browse public vault data | Public discovery and vault detail |
| Inspect assigned private rules | Operate with view-only or manager role |
| Change configuration | Operate with the operation-specific manager role |
| Deploy a new vault | **Create a SuperVault**, `/operate/create` |
| Review listing availability | **Distribute**, `/distribute` |

[Launch sequence](/operate/quickstart) covers setup; [Access and roles](/operate/permissions) defines permissions. Do not use a visible public route as evidence of authenticated access or execution readiness.
